# AI Production Incident Investigator

An AI-powered platform for investigating production-like software incidents using application logs, metrics, historical incidents, and technical documentation.

The project will progressively incorporate:

* Spring Boot backend
* PostgreSQL
* Python AI service
* Machine learning for anomaly detection
* RAG for technical documentation and historical incidents
* LLM-based investigation
* AI tool calling and agents
* MCP
* Evaluation of ML, RAG, and agent performance

All data used in this project will be synthetic or publicly available. No proprietary or employer data will be used.
